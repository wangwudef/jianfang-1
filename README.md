## 使用示例

### 1. 大盘分析

> "用简放的视角分析当前大盘走势"

AI会：
1. 调取主要指数（上证/深证/创业板）实时数据
2. 判断走势结构四阶段
3. 分析供需关系和量价行为
4. 给出仓位建议

### 2. 个股分析

> "用3L体系分析XX股票"

AI会：
1. 查个股行情和K线走势 → 判断L3量价择时
2. 查板块涨幅和RPS → 判断L1动量主线
3. 查基本面和产业逻辑 → 判断L2最强逻辑
4. 综合给出买卖建议

### 3. 交易心理

> "我总是拿不住盈利的股票，怎么办？"

AI会用简放的「静坐的力量」「无我心理」「瓦伦达效应」等模型分析问题。

## 决策启发式速查

1. **大盘定仓位** — 上升重仓、震荡中仓、下降轻仓
2. **只在第二阶段交易** — 不抄底不接飞刀
3. **买点三要素** — 关键点+关键信号+大盘配合
4. **第一时间止损** — 触发即走，不犹豫不补仓
5. **顺势重仓，逆势轻仓** — 仓位的本质是风控
6. **一年新高筛选** — 新高说明供需向好
7. **板块效应优先** — 先看板块再看个股
8. **卖出同样重要** — 强势卖出是专业交易者的技能
9. **加速无买点** — 加速上涨段不追买
10. **好公司≠好股票** — 好公司也需要好价格好趋势
11. **简单即高效** — 少则得，多则惑
