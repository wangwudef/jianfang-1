## 这是什么？

这是一个 **WorkBuddy AI Skill**，全面蒸馏了 **简放**（微博：交易者简放，公众号：简放/简无知）的3L交易体系。不依赖角色扮演，专注提供客观可执行的趋势交易分析框架。

简放是A股职业趋势交易者，3L交易体系创始人，著有《交易至"简"：交易思维模式训练与实战心法》。其体系以**供需关系为第一性原理**，以**走势结构为地图**，以**概率优势为核心**。

## 使用示例

### 1. 完整每日复盘

> "做复盘"

AI自动执行5步：
1. 查大盘数据 → 判断走势结构+四阶段
2. 查板块数据 → 判断动量主线和轮动
3. 查持仓数据 → 逐只评估持仓状态
4. 整理观察池 → P0/P1/P2三级分级
5. 输出明日If-Then计划

### 2. 选股

> "帮我筛选今日股票池"

AI按引擎流程：
1. 锁定当前动量主线板块
2. 在主线内筛上升趋势+一年新高个股
3. 用量价行为过滤
4. 逻辑确认
5. 输出≤10只精选候选池

### 3. 买卖点诊断

> "分析中际旭创当前的买卖点"

AI输出：
- 当前状态（放量突破/缩量回踩/加速风险等6种之一）
- 3L评分（L1动量强弱 + L2逻辑强弱 + L3择时买卖区）
- 明确结论（买入/持有/减仓/卖出/等待）
- 风险提示（触发条件+失效点+仓位上限）

### 4. 买前十问

> "帮我跑一下买前十问，准备买入XX"

AI逐条检查10个条件，任一不通过则暂停操作。

## 心智模型概览

| # | 模型 | 一句话 |
|---|------|--------|
| 1 | 供需关系是第一性原理 | 股价变化的本质是供需不平衡 |
| 2 | 走势结构四阶段 | 只在第二阶段重仓参与 |
| 3 | 3L交易体系 | 动量选方向，逻辑选质量，量价选时机 |
| 4 | 概率思维与复利思维 | 单笔随机，长期靠概率 |
| 5 | 情绪管理与无我心态 | 用规则对抗情绪 |
| 6 | 周期思维与反者道之动 | 万物皆周期，涨多必跌跌多必涨 |
| 7 | 降维打击与冲出舒适区 | 把不舒服训练成习惯 |
| 8 | 静坐的力量与加速无买点 | 持有不动的力量+加速不追 |
| 9 | 交相契合——无为境界 | 与市场合拍的最高境界 |
| 10 | 鱼漂思维与试错思维 | 只在鱼群聚集处下竿 |
| 11 | 强势思维和弱势思维 | 强者恒强，不做弱者 |
| 12 | 知止思维与第一时间思维 | 知道何时止，知道何时动 |

## 决策启发式速查

1. **大盘定仓位** — 上升重仓、震荡中仓、下降轻仓
2. **只在第二阶段交易** — 不抄底不接飞刀
3. **买点三要素** — 关键点+关键信号+大盘配合
4. **第一时间止损** — 触发即走，不犹豫不补仓
5. **顺势重仓，逆势轻仓** — 仓位的本质是风控
6. **一年新高筛选** — 新高说明供需向好
7. **板块效应优先** — 先看板块再看个股
8. **卖出同样重要** — 强势卖出是专业交易者的技能
9. **加速无买点** — 加速上涨段不追买
10. **好公司≠好股票** — 好公司也需要好价格好趋势
11. **简单即高效** — 少则得，多则惑
