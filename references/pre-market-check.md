## 特殊场景追加检查

### 恐慌模式（外部事件导致急跌时加做）

```
□ 主线逻辑被证伪了吗？→ 是=不买 / 否=继续
□ 个股处于第二阶段吗？→ 是=继续 / 否=不买
□ 恐慌次日出现阳吞阴/下影线了吗？→ 是=可买 / 否=再等一天
□ 止损设在恐慌低点下方-5%
□ 单笔仓位≤计划仓位50%（恐慌买点首次建仓只建一半）
```

### 加速模式（主线大涨时加做）

```
□ 已持有 → 设好移动止盈，不主动卖
□ 空仓 → 加速无买点，不追
□ 加仓 → 等缩量回踩再说
```

## 默念

> 每天≤2笔，只在主线内，买入先看止损，价格是价格其他是其他。
