# 每日投资分析系统 — 完整输出模板

> 此文件为 `SKILL.md` 中 ⚡ 每日投资分析系统 的详细模板和输出格式。
> 在执行复盘/选股/诊断/持仓管理/交易检查/交易复盘时，严格按以下格式输出。

---

## 模块1：每日晚间复盘（输出格式）

### 大盘环境
```
【大盘环境】
市场状态：[上升趋势 / 区间震荡 / 下降趋势]
四阶段定位：第[一/二/三/四]阶段
成交量变化：[放量/缩量/平量]（较前一日+/-%）
供需格局：[需求主导/供应主导/供需平衡]
关键观察：[一句话总结今日关键信号]
仓位建议：[重仓70-100% / 中等50-70% / 轻仓0-30%]
```

### 主线强弱评估
```
【主线分析】
当前核心主线：[板块]（状态：启动/加速/维持/衰退）
次线/轮动方向：[板块]
退潮方向：[板块]
最强逻辑支撑：[一句话]
主线持续性：[逻辑驱动/资金驱动/情绪驱动/事件驱动]
```

### 持仓评估
```
【持仓评估】
[股票名]：[HOLD/REDUCE/EXIT/WATCH]
  止损位：[价格]
  关键观察：[量价行为描述]
  行为风险：[潜在心理陷阱]
```

### 观察池
```
【观察池】
P0 🔴 [股票名]：[买点描述] → 计划：[突破/回踩] + [仓位]
P1 🟡 [股票名]：[等待什么信号] → 条件：[触发条件]
P2 ⚪ [股票名]：[逻辑简述]
```

### 明日If-Then计划
```
【明日 If-Then 计划】
▸ 如果大盘[条件]，则[动作+仓位]
▸ 如果[股票]出现[信号]，则[操作]
▸ 如果[持仓]触发止损，则[退出]
▸ 如果[意外情况]，则[应对]
```

## 模块2：股票筛选引擎（流程）

**Step 1**：锁定当前2-3个动量最强的板块方向 → `aiwencai` / `mx-finance-search`
**Step 2**：在这些板块内筛「上升趋势」「一年新高」「RPS>90」的个股
**Step 3**：量价行为过滤 — 排除加速段/放量滞涨/破位；保留突破/缩量回踩
**Step 4**：逻辑确认 — 排除纯题材无业绩支撑的标的
**Step 5**：精选≤10只，按优先级输出

**输出格式**：
```
【今日精选股票池】
P0 🔴 [股票名] | 板块：[板块]
  买点信号：[突破/缩量回踩/中继]
  关键位置：[支撑位/买入区间] | 止损位：[价格]
  仓位上限：[比例] | 逻辑：[一句话]
P1 🟡 [股票名] | 板块：[板块] ...
```

## 模块3：买卖点诊断（6种状态）

| 状态 | 识别条件 | 建议 |
|------|---------|------|
| 🚀 放量突破 | 量>前5均量1.5倍+突破关键阻力 | 持有/回踩确认介入 |
| ✅ 缩量回踩 | 回踩关键支撑+量明显萎缩 | 加仓/建立底仓 |
| ⚠️ 加速风险 | 连续大涨+放量+远离均线 | 不追买；持有设移动止盈 |
| ❌ 假突破 | 突破后3天放量跌回 | 放弃/减仓止损 |
| 🛑 破位退出 | 跌破关键支撑+放量 | 无条件止损 |
| ⏳ 等待 | 无明确信号 | 不动 |

**输出格式**：
```
【买卖点诊断】[股票名]
当前状态：[6选1]
L1动量：[强/中/弱] | L2逻辑：[强/中/弱] | L3择时：[买入/持有/卖出区]
结论：[买入/持有/减仓/卖出/等待]
```

## 模块4：持仓管理（4级评级）

| 评级 | 条件 | 动作 |
|------|------|------|
| **HOLD** | 上升趋势完好+无加速+止损未触发 | 不动，让利润奔跑 |
| **REDUCE** | 趋势仍在但出现警示 | 减1/3~1/2 |
| **EXIT** | 破位/止损触发/趋势逆转 | 当天无条件执行 |
| **WATCH** | 走势模糊/等待确认 | 不动，等信号 |

**输出格式**（每只持仓）：
```
[股票名] | 成本:[价] 现价:[价] 盈亏:[+/-%]
  评级：[HOLD/REDUCE/EXIT/WATCH]
  止损位：[价] | 趋势风险：[量价描述] | 行为风险：[心理陷阱]
```

## 模块5：买前十问（完整检查清单）

```
【买前十问】[股票名]
□ 1 大盘环境：[是/否] 上升或震荡？（下降趋势禁止开仓）
□ 2 动量主线：[是/否] 处于主线板块内？RPS>
□ 3 走势阶段：[是/否] 第二阶段（上升趋势）？
□ 4 买点确认：[是/否] 明确买点信号？
□ 5 止损设置：止损位[价] 最大亏损[%]（需≤2%）
□ 6 仓位合理：计划仓位[%]
□ 7 逻辑支撑：[是/否] 有基本面逻辑？
□ 8 不是加速段：[是/否] 不在连续大涨后？
□ 9 不是补仓：[是/否] 非补充亏损头寸？
□ 10 风险验证：[是/否] 有止损触发后预案？
结论：[全部通过→执行 / 第X项不通过→暂停]
```

## 模块6：交易复盘（标记体系）

| 标记 | 含义 |
|------|------|
| ✅ SYSTEM_OK | 按规则交易，接受结果 |
| ✅ GOOD_LOSS | 按规则止损，正确亏损 |
| ⚠️ LUCKY_PROFIT | 未按规则但侥幸盈利 |
| ❌ RULE_VIOLATION | 违反规则导致亏损 |

**常见行为错误**：不敢上 / 拿不住 / 追高 / 硬扛

**输出格式**：
```
【交易复盘】[股票名]
买入理由：[按体系/随意] | 卖出理由：[按体系/随意]
结果：[盈利/亏损]
标记：[SYSTEM_OK/GOOD_LOSS/LUCKY_PROFIT/RULE_VIOLATION]
反思：[一句话教训] | 改进：[下次如何做]
```
